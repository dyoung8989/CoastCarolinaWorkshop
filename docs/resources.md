# Resources and glossary

These are reference links for continuing the workshop, not required accounts or paid purchases.

- [Google Colab introduction](https://colab.research.google.com/notebooks/intro.ipynb): revisit notebook basics.
- [spaCy introductory guide](https://spacy.io/usage/spacy-101): understand tokens, sentences, and entities.
- [scikit-learn model evaluation](https://scikit-learn.org/stable/modules/model_evaluation.html): learn how predictions are assessed.
- [Hugging Face course](https://huggingface.co/learn/nlp-course/chapter1/1): explore language models after the workshop.
- [Write the Docs](https://www.writethedocs.org/): explore documentation practice and community resources.

| Term | Meaning in this workshop |
|---|---|
| NLP | Methods for working computationally with human language. |
| Token | A unit the parser uses, such as a word or punctuation mark. |
| Entity | A mention the model labels, such as a person or organization. |
| Heuristic | A useful shortcut that can fail. |
| Feature | A measurable input, such as document age. |
| Label/outcome | The result the model tries to predict. |
| Training set | Examples used to fit the model. |
| Test set | Examples set aside before fitting to assess predictions. |
| Logistic regression | A model that estimates the probability of a binary outcome. |
| Baseline | A simple comparison, here always choosing the most common training label. |
| Calibration | How closely predicted probabilities match observed outcome frequencies. Not established by this demo. |

Possible job-search terms: technical writer, content operations analyst, documentation quality, UX writing, content strategy, and AI evaluation. Look at the actual duties and required skills in each listing.
