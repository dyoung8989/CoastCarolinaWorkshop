# Sample documents

All examples are synthetic and contain no company documentation. `sample_doc_1.txt` is the extraction procedure. `messy_doc.txt` and `improved_doc.txt` support the evaluation comparison. The improved version deliberately allows a discussion of detail lost during rewriting.

The student notebook contains only extraction and evaluation activities; no external data or API key is required. Prediction is a separate local instructor demonstration. Historical assumptions for the former prediction example are documented in [model notes](../docs/model-notes.md).
