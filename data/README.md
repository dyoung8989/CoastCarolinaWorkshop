# Sample documents

All examples are synthetic and contain no company documentation. `sample_doc_1.txt` is the extraction procedure. `messy_doc.txt` and `improved_doc.txt` support the evaluation comparison. The improved version deliberately allows a discussion of detail lost during rewriting.

The prediction dataset is generated in the notebook with seed 42; no external data or API key is required. Its label-generation assumptions are documented in [model notes](../docs/model-notes.md).
